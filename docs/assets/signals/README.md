# Signals

CTA rail signal assets, used as a visual metaphor for the course's AI-use policy (see the "Student AI Use" section of [`docs/faq.md`](../../faq.md)).

The course's three main "phases" in `faq.md` are as follows:
- **Double red** (`signal-01-stop-stay.svg`) — no use of AI/LLM-based tools.
- **Yellow over red** (`signal-02-caution-main.svg`) — limited, optional, specific use cases for AI/LLM-based tools, use carefully. (The artwork is yellow on top; earlier versions of this README called it "red/yellow.")
- **Double yellow** (`signal-09-caution-restricted.svg`) — choose carefully where you use AI/LLM-based tools. When using AI/LLM-based tools, use carefully.
