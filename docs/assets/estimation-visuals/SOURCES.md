# Estimation Visuals — Sources

> _Note: this file and the figures were drafted by an LLM coding system and have not yet been reviewed._

All figures are generated by `make_estimation_figures.py` (run it with `docs/slides/.venv/bin/python3`). Used in the Week 7, Day 2 and Week 12, Day 2 slides.

- `vox-populi.svg` — the synthetic 787-guess reconstruction in `datasets/galton-vox-populi-1907/`, which matches the quantiles in Francis Galton, ["Vox Populi"](https://doi.org/10.1038/075450a0), *Nature* 75 (1907): 450–451. Individual guesses are reconstructed, not Galton's.
- `vox-populi-guesses.svg` — the same histogram with only the median guess marked, the first frame before `vox-populi.svg` in the Week 12, Day 2 slides.
- `adams-wabash-weekdays.svg` — `datasets/cta-ridership/` daily station entries, Adams/Wabash (`station_id` 40680), weekdays in 2025.

The `vox-classis-*.svg` figures are generated by `make_vox_classis_figures.py` (run it the same way), which reuses the drawing code in `datasets/galton-vox-populi-1907/vox-classis/plot-estimates.py` with this guide's palette and font. They show CS 418 Fall 2026 Homework 8 estimates from `datasets/galton-vox-populi-1907/vox-classis/`, which mix in a few synthetic decoy values (see that folder's README). Rerun the script when `results.csv` there changes.

- `vox-classis-turnout.svg`, `vox-classis-uic-halsted.svg`, `vox-classis-cta-rail.svg` — the class estimates and their median. The UIC-Halsted plot leaves off one estimate of 731,135 and the CTA rail plot leaves off two, of 90,000,000 and 13,000,000; the medians and n include them.
- `vox-classis-turnout-actual.svg` — adds the provisional actual turnout, 46.4% (95% interval 45.7–47.1%), modeled from NBC's Illinois governor vote count as of November 4, 2026 and the UF Election Lab's voting-eligible population; sources in `results.csv`. Not the final figure.
- `vox-classis-uic-halsted-actual.svg` — adds the actual value, 6,469 rides, from [CTA Ridership, 'L' Station Entries, Daily Totals](https://data.cityofchicago.org/Transportation/CTA-Ridership-L-Station-Entries-Daily-Totals/5neh-572f), City of Chicago Data Portal (`station_id` 40350, August 25, 2026).
