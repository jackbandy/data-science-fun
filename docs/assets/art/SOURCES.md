## Escher-like Tessellations (Creative Commons)

These are mathematical tessellations inspired by M.C. Escher's style, created digitally.

### Escher-like Files

1. **tiling_1.png**
   - Title: Escher like tiling (Fractal visualization)
   - Description: A mathematical tessellation based on a [Julia set](https://en.wikipedia.org/wiki/Julia_set), creating repeating patterns similar to M.C. Escher's work. Julia sets are fractals generated by iterating complex numbers.
   - Dimensions: 2,000 × 2,000 pixels (803 KB)
   - Source: [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Escher_like_tiling.png)
   - License: Creative Commons Attribution-ShareAlike 4.0 International
   - Data Science Theme: Fractals, self-similarity, recursive patterns (Weeks 5-6, 10)

2. **tiling_basilica_julia.png**
   - Title: Escher like tiling — Basilica Julia set
   - Description: The [Basilica Julia set](https://en.wikipedia.org/wiki/Julia_set#Examples) is generated from the quadratic polynomial f(z) = z² - z, creating a distinctive pattern with two main lobes. Named for its resemblance to a basilica, it demonstrates how different parameters produce radically different fractal structures.
   - Dimensions: 2,000 × 2,000 pixels (567 KB)
   - Source: [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Escher_like_tiling_Basilica_Julia_set.png)
   - License: Creative Commons Attribution-ShareAlike 4.0 International
   - Data Science Theme: Complex mathematical patterns, boundary detection (Weeks 8-10)

3. **tiling_douady_rabbit_julia.png**
   - Title: Escher like tiling — Fat Douady rabbit Julia set
   - Description: The [Douady rabbit](https://en.wikipedia.org/wiki/Julia_set#Examples) is a Julia set with a rabbit-like shape, named after mathematician Adrien Douady. The "fat" version shows the full filled set with thick connecting filaments, illustrating how [iterative processes](https://en.wikipedia.org/wiki/Iteration) create intricate self-similar boundaries from simple mathematical rules.
   - Dimensions: 2,000 × 2,000 pixels (646 KB)
   - Source: [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Escher_like_tiling_Fat_Douady_rabbit_Julia_set.png)
   - License: Creative Commons Attribution-ShareAlike 4.0 International
   - Data Science Theme: Iterative refinement, parameter exploration, manifold geometry (Week 10)
