# Michalski Trains Attribution and Licensing

## Michalski Train Diagrams

Both files are cropped figures depicting Michalski's original set of trains, a classic pattern-recognition/induction dataset.

### Files

1. **figure10-michalski-original-trains.pdf**
   - Title: Figure 10, "Michalski's original set of trains"
   - From: Helff, Stammer, Shindo, Dhami, and Kersting, *V-LoL: A Diagnostic Dataset for Visual Logical Learning*
   - Source: [arXiv:2306.07743](https://arxiv.org/pdf/2306.07743)

2. **figure4-michalski-ieee-1980.pdf**
   - Title: Fig. 4, trains going East/West
   - From: Ryszard S. Michalski, "Pattern Recognition as Rule-Guided Inductive Inference," *IEEE Transactions on Pattern Analysis and Machine Intelligence*, PAMI-2(4), 1980
   - Source: [IEEE Xplore, document 4767034](https://ieeexplore.ieee.org/abstract/document/4767034)
