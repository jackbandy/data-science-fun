# Recognize This Font? — Attribution and Licensing

> _Note: this file was drafted with an LLM._

Generated by `make_font_figures.py` (`uvx --from fonttools --with brotli python make_font_figures.py`). Each typeface sets "Example Font" once in black on white (`*-plain.svg`) and once in a themed color scheme (`*-themed.svg`). The letters are converted to outlined paths, so no font file is embedded or redistributed. None of the fonts is committed; the script reads them from macOS or from the git-ignored `.fonts/` folder next to it.

Theme colors for Avatar, Olivia Rodrigo, and KPop Demon Hunters are approximations chosen for the slides: Avatar in glowing cyan on dark blue; Olivia Rodrigo in pink on a pale blue sky, after the album's "shades of blue and light pink" (Wikipedia, ["You Seem Pretty Sad for a Girl So in Love"](https://en.wikipedia.org/wiki/You_Seem_Pretty_Sad_for_a_Girl_So_in_Love)); KPop Demon Hunters in a pink-purple-cyan gradient on near-black.

IKEA and Brat use sourced values (checked 28 Sep 2026):

- IKEA blue `#0058A3` and yellow `#FFDB00`: the CSS custom properties `--colour-static-ikea-brand-blue: 0, 88, 163` and `--colour-static-ikea-brand-yellow: 255, 219, 0` served on [ikea.com](https://www.ikea.com/us/en/). Third-party color sites list other values (e.g. `#0058AB`, `#FBD914`).
- Brat green `#8ACE00`: the flat background of the cover art on [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Charli_XCX_-_Brat_(album_cover).png) (2048 × 2048 PNG, every background pixel `rgb(138, 206, 0)`). The print spec is Pantone 3507 C; Pantone's own [3507 C swatch image](https://www.pantone.com/color-finder/3507-C) renders as `#AFD001`, and its official hex value sits behind a Pantone Connect login. The cover's lettering is soft at full resolution, which the light blur imitates; the lowercase text is set smaller than the others, as on the cover.
