# Sampling Visuals — Sources

> _Note: this file and the figures were drafted by an LLM coding system and have not yet been reviewed._

All figures are generated by `make_sampling_figures.py` (run it with `docs/slides/.venv/bin/python3`). Simulated figures use the fixed seed 418, so they regenerate identically. Used in the Week 7, Day 2 slides.

- `home-population-sample.svg`, `clt-panels.svg`, `standard-error.svg`, `ci-coverage.svg` — `datasets/cook-county-home-sales-2025/`, filtered as in `week8/make_week8_figures.py`, treated as the population.
- `sampling-designs.svg` — simulated.
- `big-data-paradox.svg` — hypothetical poll; the biased sample's 60% response share is invented. The idea follows Valerie C. Bradley et al., ["Unrepresentative Big Surveys Significantly Overestimated US Vaccine Uptake"](https://doi.org/10.1038/s41586-021-04198-4), *Nature* 600 (2021): 695–700.
