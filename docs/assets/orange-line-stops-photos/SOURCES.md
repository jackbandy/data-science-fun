# Sources & Licenses — orange-line-stops-photos

Files are named `stopNN-<stop>-<letter>.<ext>` where NN is the stop's position
along the Orange Line (Harold Washington Library → Midway, counterclockwise through
the Loop then southwest to Midway Airport).
