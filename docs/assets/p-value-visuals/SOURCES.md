# p-Value Visuals — Sources

> _Note: this file and the figures were drafted by an LLM coding system and have not yet been reviewed._

All figures are generated by `make_p_value_figures.py` (run it with `docs/slides/.venv/bin/python3`). Simulated figures use the fixed seed 418, so they regenerate identically. Used in the Week 7, Day 1 slides.

- `resume-permutation.svg` — `datasets/resume-audit-bertrand-mullainathan/`, from Marianne Bertrand and Sendhil Mullainathan, ["Are Emily and Greg More Employable Than Lakisha and Jamal?"](https://doi.org/10.1257/0002828042002561), *American Economic Review* 94, no. 4 (2004): 991–1013. The permutation test (10,000 shuffles of the name labels) is ours.
- `z-test-tail.svg`, `many-tests.svg` — plain normal and probability math. The battery-life z-test (z = −0.555) follows Elena Zheleva's CS 418 hypothesis-testing slides (Feb. 10, 2026).
- `dance-of-p-values.svg`, `p-value-distributions.svg` — simulated two-group experiments (n = 32 per group, true difference 10, SD 20), after Geoff Cumming's ["Dance of the p Values"](https://www.youtube.com/watch?v=5OL1RqHrZQ8) demonstration. The parameters are ours, chosen to give a medium effect (d = 0.5).
- `significance-vs-size.svg`, `two-replications.svg` — hypothetical estimates and standard errors, chosen for illustration.
