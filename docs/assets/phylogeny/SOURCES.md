# Elephantidae Phylogeny Diagram

`elephantidae-cladogram.svg` is a locally-authored diagram (Libre Franklin type, matching the deck's other original SVGs). Its topology follows the "Proboscidea phylogeny based on morphological and DNA evidence" cladogram in the Wikipedia [Elephant](https://en.wikipedia.org/wiki/Elephant#Taxonomy) article, simplified to the Elephantidae-level split: (*Loxodonta*, *Palaeoloxodon*) and (*Mammuthus*, *Elephas*).

It embeds four tip images, matching the ones used in that same Wikipedia cladogram:
