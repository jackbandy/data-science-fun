# Model Evaluation Visuals — Sources

> _Note: this file and the figures were drafted by an LLM coding system and have not yet been reviewed._

All figures are generated by `make_model_evaluation_figures.py` (`python3 make_model_evaluation_figures.py [name ...]`). Cross-validated predictions use a stratified 5-fold split with seed 418, so the figures regenerate identically. Used in the Week 10, Day 2 slides.

- **Data** — `datasets/classification-examples/penguins.csv`, the 342 penguins with all four measurements; bill length and flipper length, standardized. Allison Horst, Alison Hill, and Kristen Gorman, [palmerpenguins](https://doi.org/10.5281/zenodo.3960218) (2020), CC0; data originally from Gorman, Williams, and Fraser, *PLoS ONE* 9(3): e90081 (2014), <https://doi.org/10.1371/journal.pone.0090081>.
- `holdout-*` — train/test split and 5-fold cross-validation, after Lau, Gonzalez, and Nolan, *Learning Data Science*, [16.2 "Train-Test Split"](https://learningds.org/ch/16/ms_train_test.html) (Fig. 16.1) and [16.3 "Cross-Validation"](https://learningds.org/ch/16/ms_cv.html) (Fig. 16.3). Redrawn; the 274/68 split is ours.
- `chinstrap-waffle`, `resample-*`, `confusion-chinstrap-*`, `pr-cutoff-*`, `pr-curve` — Week 9's "Chinstrap vs. the rest," scored by a logistic regression (scikit-learn defaults). The imbalance, resampling, confusion-matrix, and ranking-cutoff ideas follow Elena Zheleva's CS 418 slides (Mar. 19, 2026).
- `f1-mean` — plain math: harmonic vs. arithmetic mean of precision and recall.
- `confusion-penguins` — three species, an RBF-kernel SVM (scikit-learn defaults).
- `ovr-ovo-*`, `classifier-count` — one-vs-rest and one-vs-one, after Zheleva (Mar. 19, 2026).
