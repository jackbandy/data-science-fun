# Slide Theme Fonts

Fonts used by `uic-orange-reveal.scss`.

- Danh Da Bold: downloaded from Republish, the project home for Danh Da: https://republi.sh/. The included specimen notes that Danh Da Bold is released under the SIL Open Font License.
- APHont: downloaded from American Printing House: https://www.aph.org/resources/large-print-guidelines/. Also listed on FontSpace: https://www.fontspace.com/aphont-font-f4926. APH describes APHont as free to download and usable by all, with restrictions against selling, changing, or restricting access to the font files.
- Big Shoulders: downloaded from the upstream XO Type Co repository: https://github.com/xotypeco/big_shoulders. Additional non-Google references: https://bigshoulders.me/ and https://design.chicago.gov/typography/. Copyright 2019 The Big Shoulders Project Authors, licensed under the SIL Open Font License.
- Libre Franklin: downloaded from the upstream Impallari Type repository: https://github.com/impallari/Libre-Franklin. Used as the self-hosted OFL fallback for the slide body's ITC Franklin Gothic stack because ITC Franklin Gothic itself is a commercial typeface and no permissive redistribution source was identified. Licensed under the SIL Open Font License 1.1.
- Routed Gothic: downloaded from the upstream Darren Embry repository: https://github.com/dse/routed-gothic. Project page: https://webonastick.com/fonts/routed-gothic/. Also listed on Font Meme: https://fontmeme.com/fonts/routed-gothic-font/. Licensed under the SIL Open Font License 1.1.
