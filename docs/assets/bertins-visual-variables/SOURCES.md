# Sources — `bertins-visual-variables`

> _Note: this file was drafted by an LLM._

- `bertin-visual-variables.png` — third-party raster, saved from Ken Flerlage's
  ["Revisiting Tableau Desktop
  Fundamentals"](https://datavizblog.com/2017/06/13/revisiting-tableau-desktop-fundamentals/)
  (DataVizBlog, 13 June 2017). It is a scan-style reproduction of the summary
  table of Jacques Bertin's original visual variables, from *Sémiologie
  Graphique: Les diagrammes, les réseaux, les cartes* (Gauthier-Villars, 1967;
  English: *Semiology of Graphics*, University of Wisconsin Press, 1983).
  Kept as the reference for the redraw; no license stated, so don't republish it.
- `bertins-visual-variables.svg` — original artwork (this repo), generated by
  `make_bertin_visual_variables_figure.py`. Same seven variables and same
  row order as the reference, redrawn from scratch on the repo's 1000 × 618
  golden-ratio canvas with the repo's fonts. Two deliberate departures:
  - the demonstration panels sit on a light gray (`#EEEEEE`, the `STYLE.md`
    neutral fill) instead of the original's saturated blue, which was
    competing with the marks — a mid-value blue makes the *value* ramp and the
    *colour* row nearly impossible to judge, since both are claims about
    lightness and hue against their surround;
  - the table splits at the golden section, labels taking the minor part and
    demonstrations the major part.
  The figure carries the credit line in its own bottom margin; credit Bertin for
  the taxonomy wherever it is used.

Fonts are read from `../fonts/` at build time and embedded in the SVG as base64
woff2, so nothing here needs a local copy: Big Shoulders sets the title and
Libre Franklin the table, per `../STYLE.md`. Both are SIL Open Font License 1.1
(see the `OFL.txt` beside each).
