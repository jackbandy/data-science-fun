## Glossary {.appendix}

Common knowledge
: Shared awareness about what other people know, including higher-order awareness that others know it too. Often conflated with mutual knowledge [Source: @sep-common-knowledge].

Mutual knowledge
: A proposition is mutual knowledge among a set of agents when each agent knows that proposition [Source: @sep-common-knowledge].

Consent
: Permission that is freely given, reversible, informed, enthusiastic, and specific [Source: @lee_building_consentful_2017].

Data
: Multiple datum.

Datum
: A single data point, such as a number or symbol.

Data visceralization
: Placeholder definition for Kelly Dobson's term for making data or intangible events sensory, bodily, or experientially felt rather than only visually represented [Source: @mit_media_lab_dobson_2014; @wernimont_pandemic_death_counts_2022].

Ethics
: Acting well in the world [Source: @burton_computing_2023].
