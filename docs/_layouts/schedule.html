Everything the schedule says comes from two files — edit those, not this one: _data/schedule.csv units, weeks, class days, dates, topics, notes _includes/schedule-topics.md what happens each day, plus source materials They sit in different folders because Jekyll parses anything in _data/ into site.data.* but ignores .md there, and only an _includes/ file can be pulled in as raw, unrendered markdown. The homepage table and the syllabus build read the same CSV, so the spine can never disagree. Slide decks (slides/weekN.html) and worksheets (worksheets/NN-weekWW-dayD.pdf) are linked when the file exists, so nothing has to be typed twice.
