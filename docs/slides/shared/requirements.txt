# Direct dependencies only. Builds install requirements.lock, which lock_requirements.sh resolves from this file with the shared libraries pinned to the Python Yard's versions (pyodide-pins.txt); re-run it after any edit here.
jupyter
nbformat
# numba (pulled in via arviz, used by week6's pymc deck) sets the real ceiling
# here. It compiles against NumPy internals, so each numba release supports
# NumPy only up to a known version. Left uncapped, the resolver would rather
# drop numba -- taking pytensor down several major versions with it -- than
# report the conflict, and the week6 deck renders degraded instead of failing
# loudly. Mirroring numba's own ceiling keeps that resolution honest.
#
# numba 0.67 requires numpy<2.6, so that is the cap. Raise it in step with
# numba's next release rather than ahead of one.
#
# For history: numba <=0.66 stopped at numpy<2.5 because it called
# np.row_stack, which NumPy removed in 2.5. numba 0.67 fixed that.
numpy<2.6
# polars 2.0 removed DataFrame.__dataframe__, which seaborn 0.13 needs to accept polars frames (week6, week11). Lift once seaborn handles polars 2 natively.
polars<2
seaborn
plotnine
pyarrow
# The old <3.11 cap guarded arviz's `matplotlib.style.core` import; arviz 0.22 and 1.3 both import cleanly under matplotlib 3.11 (checked Oct 2026), so this is now a plain guard against the next minor release.
matplotlib<3.12
statsmodels
# week9's k-NN and decision tree demo; 1.x API (KNeighborsClassifier, plot_tree).
scikit-learn>=1.5,<2
# week8's R-style plot(lm) diagnostics; 0.x, so cap at the next minor in case the API moves.
lmdiag>=0.4.1,<0.5
networkx
# Figure scripts only: the CIELAB conversion in clustering-visuals' color-compression figures; 0.x, so cap at the next minor.
scikit-image>=0.26,<0.27
pymc
