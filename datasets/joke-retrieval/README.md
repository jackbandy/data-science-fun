# Joke Retrieval: Recognizing the Same Joke Told Differently

JokesCorpus archives used in "Joke Retrieval: Recognizing the Same Joke Told Differently", CIKM 2008. For educational purposes only.

## Files

- `JokesCorpus-txt.tgz`: plain-text JokesCorpus archive from the source page.
  - compressed size: approximately 1.7 MB
  - archive listing: 10,946 entries
  - includes `JokesCorpus-txt/jokes/`, `metajokes-labels.txt`, and `typesOfRemovedJokes.txt`
- `JokesCorpus-xml.tgz`: XML JokesCorpus archive from the source page.
  - compressed size: approximately 2.7 MB
  - archive listing: 12,380 entries
  - includes `JokesCorpus-xml/jokes/`, `JokesCorpus-xml/filtered/`, and `metajokes-labels.txt`
  - joke XML files include metadata such as category, title/name, and source URL when available

## Sources

- Lisa Friedland software/data page: https://lfriedl.github.io/code.html
- Plain-text archive: https://lfriedl.github.io/code/JokesCorpus-txt.tgz
- XML/source-URL archive: https://lfriedl.github.io/code/JokesCorpus-xml.tgz
- Publication listing: https://lfriedl.github.io/pubs.html

The linked source page describes this as the corpus and labels used in the CIKM 2008 joke-retrieval paper. This folder keeps the upstream archives intact rather than extracting or transforming the files.
