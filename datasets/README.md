# Datasets for CS 418

These are mostly from the chicago data portal:
https://data.cityofchicago.org/

Datasets are pre-processed and intended only for educational purposes.

### Guidelines

* keep file sizes `< 50 MB` (for github and general portability)
* use CSV or other plain-text formats
* include a short README in each dataset folder
* note the source(s) for each file
