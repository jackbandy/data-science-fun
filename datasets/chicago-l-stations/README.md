# Chicago L Stations

derived CSV of CTA L stop records with station names, service flags, and location data, prepared from public Chicago transit data. For educational purposes only.

## Files

- `CTA_List_of_'L'_Stops_20260527.csv`: L-stop records with the following columns:
  - `STOP_ID`
  - `DIRECTION_ID`
  - `STOP_NAME`
  - `STATION_NAME`
  - `STATION_DESCRIPTIVE_NAME`
  - `MAP_ID`
  - `ADA`
  - `RED`
  - `BLUE`
  - `G`
  - `BRN`
  - `P`
  - `Y`
  - `Pnk`
  - `O`
  - `Location`

## Sources

- City of Chicago Data Portal: https://data.cityofchicago.org/Transportation/CTA-System-Information-List-of-L-Stops/8pix-ypme
- City of Chicago Data Portal map view: https://data.cityofchicago.org/Transportation/CTA-System-Information-List-of-L-Stops-Map/zbnc-zirh/about

The linked data portal record is a Chicago Transit Authority dataset published through the City of Chicago Data Portal. This CSV is a separate derived file prepared from local source data associated with the CTA L-stops dataset and related public materials.
