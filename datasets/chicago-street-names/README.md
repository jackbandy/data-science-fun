# Chicago Street Names

derived CSV of Chicago street names with suffix and address range fields, prepared from public City of Chicago data. For educational purposes only.

## Files

- `Chicago_Street_Names_20260527.csv`: Street-name records with the following columns:
  - `Full Street Name`
  - `Direction`
  - `Street`
  - `Suffix`
  - `Suffix Direction`
  - `Min Address`
  - `Max Address`

## Sources

- City of Chicago Data Portal: https://data.cityofchicago.org/Transportation/Chicago-Street-Names/i6bp-fvbx
- City of Chicago Data Portal view based on Chicago Street Names: https://data.cityofchicago.org/Transportation/chicago-streets-and-directional-addresses/thfd-f53i

The linked data portal record is a City of Chicago public dataset and related community view. This CSV is a separate derived file prepared from local source data associated with the Chicago street names dataset and related public materials.
