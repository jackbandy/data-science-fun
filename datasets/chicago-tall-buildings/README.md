# Tall Buildings in Chicago

filtered CSV of buildings with 10 or more stories, derived from public Chicago building data. For educational purposes only.

## Files

- `tall_buildings_public.csv`: Buildings filtered to `stories >= 10` with the following columns:
  - `building_id`
  - `building_name_1`
  - `building_name_2`
  - `stories`
  - `number_of_units`
  - `year_built`
  - `building_sq_ft`

## Sources

- City of Chicago Data Portal: https://data.cityofchicago.org/d/hz9b-7nh8
- City of Chicago GitHub release: https://github.com/Chicago/osd-building-footprints/tree/master

The linked GitHub repository was shared under the MIT License; this CSV is a separate derived file prepared from local source data associated with the Chicago building footprints dataset and related public materials.
