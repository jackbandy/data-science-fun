# ICD-10-CM (International Classification of Diseases, 10th Revision, Clinical Modification)

FY2026 code descriptions from the CDC, for educational use. Downloaded June 2026.

Collected after reading Bowker and Star, *Sorting Things Out: Classification and Its Consequences* (MIT Press, 1999), which uses ICD as a recurring case study.

## Files

- `icd10cm-codes-2026.txt`: all 74,719 billable and category codes, tab-separated — `CODE` and `DESCRIPTION`. Simplest file for most uses.
- `icd10cm-order-2026.txt`: fixed-width tabular order file with sequence number, code, validity flag (0 = category header, 1 = billable), short description, and long description.
- `icd10cm-codes-addenda-2026.txt`: additions, deletions, and revisions to the code set for FY2026.
- `icd10cm-order-addenda-2026.txt`: same changes in tabular order format.
- `icd10cmCodesFile.pdf` / `icd10OrderFiles.pdf`: documentation of file formats.

## Sources

- CDC FTP: https://ftp.cdc.gov/pub/health_statistics/nchs/publications/ICD10CM/2026/
- CDC ICD-10-CM page: https://www.cdc.gov/nchs/icd/icd-10-cm/files.html

Files are produced by the National Center for Health Statistics (NCHS) and are in the public domain.
